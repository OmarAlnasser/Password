# Lantern Nights

Co-op survival and creature collecting for Roblox, built mobile-first for 1–6 players.
By day you gather, craft, build and tame. By night you defend the campfire against
waves that get harder each night, with a boss every 10 nights.

A Rojo project written in strict-typed Luau, with a Fusion 0.3 UI.
