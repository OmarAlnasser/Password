What's new in 0.1.3

- Windows: Khazna now comes with a setup (windows-x64-setup.exe). It installs for your user only, without admin rights, adds Khazna to the Start menu and the desktop, and can be removed from Installed apps.
- Windows updates now install in place: Khazna closes, the new version is installed without a window, and Khazna opens again. If an update cannot finish, the previous version is kept and opens instead.

Once, on Windows, if you use 0.1.2 or earlier: download windows-x64-setup.exe from this release, run it, then delete your old Khazna folder. Your vault is kept: it lives in your user's app data, not in the app folder. In Chrome, Edge or Brave, open Settings > Browser extension in Khazna and use Load unpacked again with the new extension folder shown there.
